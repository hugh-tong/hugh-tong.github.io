# 你好，我是 tttt

这里是我的个人技术博客。我把它当作一个长期维护的工程笔记本：记录问题、验证方法、源码阅读和实际踩坑，也会整理值得回看的官方文档、论文与社区讨论。

## 我关注的方向

- OpenFOAM 求解器、边界条件、网格处理与并行工具
- CFD 中的离散格式、压力-速度耦合、湍流模型和数值稳定性
- 多区域传热、自由液面和动态网格等工程问题
- Linux、WSL、C/C++、Python、VS Code 以及计算工具链

## 这个博客写什么

文章大致分为三类：

1. **问题记录**：从一个报错、异常结果或配置差异出发，保留排查过程和验证边界。
2. **源码与理论笔记**：把 OpenFOAM 源码、离散方程和算法背景放在一起，尽量标注适用版本。
3. **工具与维护**：记录开发环境、网格工具、并行计算和本站本身的维护方法。

我会尽量区分“已经运行验证的结论”“根据源码得到的解释”和“待验证的线索”，避免把一次案例观察写成普遍规律。
