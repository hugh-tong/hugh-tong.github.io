01 / FUNDAMENTALS

首先明确：能量守恒的不是温度

温度是状态变量，不是守恒量。热力学第一定律描述系统储能的变化与热量、功和物质携带能量之间的收支关系。

内能
e

微观热运动与相互作用能；单位 J/kg。

比焓
h

内能与流动功组合；单位 J/kg。

总比能
E

内能 + 宏观动能；此处暂不含势能。

其中 是随流体微团运动的物质导数；密度、压力和温度由热物性关系联系起来。热量与功是传递能量的方式，并非流体中储存的两种独立“物质”。

04 / CONCEPTUAL DISTINCTION

能量方程与不可压缩温度输运方程，到底差在哪里？

守恒物理

一般能量方程

  • 求解焓、内能或总能量
  • 热物性模型把能量与温度、压力联系起来
  • 可考虑压力功、黏性耗散等效应
  • 便于多物理耦合与严格能量收支
受限模型

不可压温度输运

  • 直接求解温度 T
  • 常用常密度与定比热容假设
  • 省去热机械效应或证明其可忽略
  • 满足假设时仍是正确的能量守恒模型

一个非常容易写错的细节：不可压流的焓不一定只随 T 变化

对严格密度不变、热膨胀系数 β = 0 的物质，；因此在焓方程中，Dh/Dt 自身包含一个 Dp/Dt / ρ。它与焓方程右边的压力项抵消，才得到温度方程中没有压力导数的结果。

结论：不可压缩的温度方程不是“完整焓方程把压力项随便删掉”的结果。 正确推导需要考虑状态方程、热容定义及压力依赖。对 Boussinesq 模型和弱可压缩模型，也应根据具体热物性近似重新判断。
判断问题温度输运形式焓 / 总能量形式
能量状态变量T，作为热量的代理变量h、e、E；经热物性关系得到 T
热容与密度变化需正确处理系数及守恒形式更自然地通过 ρh 或 ρe 表示储能
压缩与压力功简化后常省略可以保留；但是否显式出现取决于变量选择
相变与化学反应常通过附加源项或有效热容近似相焓、组分焓及相间源项的管理通常更自然
离散守恒在适用条件下可以守恒通常更方便建立一般情况下的能量预算

08 / CODE MAPPING

从 PDE 到 OpenFOAM 有限体积代码

数学形式是物理模型，有限体积离散是计算模型。最稳妥的学习方法是先写出每个面上的通量，再对应到 fvm:: 与 fvc::。

控制体形式：单位一致后，每一项都是 W

示意固定控制体、常密度与常 cp，面通量 φf=Uf·Sf 为体积通量；导热率 k 在面上处理，非正交项可能另有校正。内部面的通量对相邻单元符号相反，是全局守恒的基础。

// 常物性、不可压、固定网格；演示量纲与离散算子 // phi: 体积流量 [m³/s]，alpha = k/(rho*Cp) [m²/s] fvScalarMatrix TEqn ( fvm::ddt(T) + fvm::div(phi, T) - fvm::laplacian(alpha, T) == qDot/(rho*Cp) ); TEqn.solve();
// 教学伪代码：表示离散结构，而非可直接编译的具体 solver volScalarField& he = thermo.he(); fvScalarMatrix EEqn ( fvm::ddt(rho, he) + fvm::div(phiMass, he) + pressureAndKineticEnergyTerms + heatFluxDivergence == sourceTerms ); EEqn.solve(); thermo.correct();
不要混淆 phi：对不可压体积通量是 m³/s，对可压质量通量是 kg/s。也不要认定所有热物性库里叫 alpha、alphaEff 的量单位都一定是 m²/s；应检查变量的 dimensions() 和热通量模型。

10 / MULTIPHYSICS

加入共轭传热、蒸发和冷凝之后，会发生什么？

从“单个温度方程”走向“多区域、多相质量和能量守恒的耦合系统”。计算上的核心难点，是把界面交换以一致、守恒的方式传递给各方程。

CHT

流体 ↔ 固体

流体有对流和导热；静止固体通常只有储能与导热。界面温度和法向热通量需要满足耦合条件。

PHASE CHANGE

蒸发 ↔ 冷凝

需要质量传递率、相变焓以及相之间的能量分配，避免显式潜热与焓定义重复计数。

REAL FLUID

真实物性

cp、ρ、k、μ 可以依赖温度、压力与组成，h(T,p) 不一定能近似成 cpT。
